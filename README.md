# SEE — Space and Everyone Else

Однопользовательская оффлайн космическая sandbox-RPG для Windows.

## Текущее состояние

**Стадия:** активная разработка ядра симуляции (`sim_core`).

## Ключевые правила

- **Детерминизм:** `sim_core` не использует `thread_rng`, `SystemTime`,
  `HashMap` с RandomState. Только `BTreeMap`/`BTreeSet` и seeded RNG.
- **Лор:** персонаж — человек, не «капсулер». Три слоя развития:
  мозг (знания — навсегда), нейросеть (заменяемая), импланты
  (компенсация).
- **CI:** `cargo fmt --all`, `cargo clippy --workspace --all-targets
  -- -D warnings`, `cargo test --workspace`.

## Как собрать и запустить

```bash
cargo build --workspace
cargo test --workspace
```
